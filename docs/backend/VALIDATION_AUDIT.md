# Đối chiếu validation API

Tài liệu kiểm kê input và kết quả đã kiểm tra; không coi danh sách này là chứng nhận mọi nhánh đã được kiểm thử. Các endpoint bên dưới có tiền tố `/api/v1`. Backend lấy identity từ token; Data API nhận identity qua HTTP nội bộ và xác thực service key. 400 là lỗi input, 401 là thiếu/invalid token, 403 là sai quyền; các lỗi 404/409 phụ thuộc tài nguyên và trạng thái.

| Nhóm / endpoint | Input chính cần kiểm tra | Hiện trạng và bằng chứng |
|---|---|---|
| `POST /auth/login`, `/auth/google`, `/auth/register` | username/password; idToken; username, password, fullName, email, phone, role, shopName, shopTagline | Đã kiểm tra kiểu phone, shopTagline, role khi đăng ký ở hai tầng; test `test-auth-input.mjs`. Login/Google còn cần audit mọi giá trị biên và kết quả DB. |
| `GET /auth/me`, `PUT /auth/profile`, `POST /auth/change-password`, `/auth/seller-shop` | Token; fullName, email, phone, avatarUrl, address; currentPassword/newPassword; shopName | Có validation tại controller; profile/address có test MySQL riêng `test-address-mysql.mjs`, avatar có `test-avatar-mysql.mjs`. Profile đã chặn phone sai kiểu; cần rà soát tiếp các nhánh lỗi của từng endpoint. |
| `POST /auth/refresh`, `/auth/logout` | refreshToken | Có kiểm tra token; test refresh/password hiện có. Chưa audit lại đầy đủ nhánh sai kiểu và hết hạn trong lần này. |
| `GET /cart`, `POST /cart/items`, `PATCH /cart/items/:itemId`, `DELETE /cart/items/:itemId`, `DELETE /cart/items`, `DELETE /cart`, `POST /cart/sync`, `PATCH /cart/selection` | variantId/productId, qty, selected, replaceQty; itemId; selectedOnly/selected; items; shopId | Chặn kiểu ID giả mảng/số không an toàn, qty và boolean sai; `test-cart-validation.mjs` mock và `test-cart-sync-mysql.mjs` trên MySQL riêng. Đã chặn itemId không đúng định dạng trên sửa/xóa; cần tiếp tục rà productId và dữ liệu biên. |
| `POST /orders/preview`, `POST /orders` | items.variantId/qty, shippingMethod, voucherCode; thêm address, paymentMethod, note và header Idempotency-Key khi tạo | Giới hạn item, số lượng, phương thức và độ dài tại Data API; sửa chặn ID bị ép kiểu khi tạo đơn. `test-checkout-preview.mjs` và `test-cart-validation.mjs` dùng mock; chưa audit toàn bộ biến thể request. |
| `GET /orders`, `POST /orders/:orderId/cancel`, `POST /orders/:orderId/confirm-received` | limit, offset, orderId | Owner lọc theo user; kiểm tra ID. Phân trang hiện dùng giá trị mặc định khi input không hợp lệ; cần thống nhất contract trước khi đổi sang 400 và kiểm thử các trạng thái/owner. |
| `GET /seller/shop`, `PUT /seller/shop`, `POST /seller/shop/resubmit` | name, tagline, description, province, address, logoUrl, bannerUrl | Yêu cầu seller/admin tại Backend, Data API lấy shop theo owner; `test-shop-approval-mysql.mjs` kiểm tra quyền và trạng thái, `test-cart-validation.mjs` kiểm tra một số kiểu sai với mock. Chưa audit hết mọi input. |
| `GET /seller/products`, `POST /seller/products`, `PUT/DELETE /seller/products/:productId` | limit, offset, productId; name, categoryId, description, price, originalPrice, stock, images, status, freeShipping | Validation tại `seller-product.validation.js`; `test-seller-product-validation.mjs` kiểm tra giá/tồn và `test-cart-sync-mysql.mjs` có kiểm tra dữ liệu không đổi. Đã chặn `freeShipping` sai kiểu và `status` rỗng/sai kiểu; phân trang sai hiện được mặc định và cần thống nhất contract. |
| `GET /seller/orders`, `PATCH /seller/orders/:shopOrderId/status`, `GET /seller/images/search` | limit, offset, shopOrderId, status, q | Route yêu cầu seller/admin; truy vấn đơn theo owner, q có giới hạn 3–120 ký tự. Cần kiểm tra biên phân trang, trạng thái và lỗi phụ thuộc. |
| `GET /categories`, `GET /shops`, `GET /shops/:shopId`, `GET /products`, `GET /products/:productId` | limit, offset, q, mall/featured; ID/slug; bộ lọc danh mục, shop, giá, rating, discount, sort, ids | Bộ lọc và phân trang sai ở một số nhánh bị bỏ qua hoặc thay bằng mặc định; cần thống nhất contract và test giá trị biên trước khi đổi hành vi. |
| `GET /products/:productId/reviews`, `/reviews/eligible`, `POST /products/:productId/reviews` | productId, orderItemId, rating, comment | `test-reviews-mysql.mjs`: quyền mua, delivered, sai sản phẩm, input sai, trùng và gửi đồng thời trên MySQL riêng. Cần tiếp tục rà input ID nội bộ. |
| `POST /uploads/images` | dataUrl, purpose | Kiểm tra xác thực, mục đích, MIME/chữ ký, dung lượng và giải mã ảnh ở Backend; cần kiểm thử storage và client theo môi trường chạy. |
| `GET /vouchers/wallet`, `POST /vouchers/wallet` | page; code | `test-voucher-wallet-mysql.mjs`: owner, input, lưu đồng thời, trạng thái và phân trang trên MySQL riêng; checkout kiểm tra điều kiện lại. |
| `POST /shipping/calculate`, `PATCH /seller/orders/:shopOrderId/tracking`, `GET /orders/:orderId/tracking` | subtotal; shopOrderId, trackingCode, carrier, autoAdvanceStatus; orderId | Kiểm tra kiểu, chiều dài mã/đơn vị và boolean; `test-cart-validation.mjs` với mock. Cần kiểm tra dữ liệu và quyền thực tế ở môi trường đích. |
| `POST/GET /orders/:orderId/returns`, `GET /seller/returns`, `PATCH /seller/returns/:returnId/status` | shopOrderId, reason, detail, images, refundAmount; status, limit, offset; sellerNote | Kiểm tra nội dung và chuyển trạng thái; `test-return-status-mysql.mjs` kiểm tra owner, đồng thời và lỗi 503 khi thiếu bảng. Phân trang và trạng thái theo nghiệp vụ vẫn cần kiểm tra tiếp; `completed` không chứng minh tiền đã hoàn. |
| `GET/POST /chat/conversations`, `GET/POST /chat/conversations/:id/messages` | shopId; id, limit, offset, message, attachments | Kiểm tra ID shop, giới hạn tin nhắn và attachments ở hai tầng; phân trang test mock; chưa audit mọi cấu trúc dữ liệu đính kèm. |
| `POST /reports`, các route `/admin/...` | targetType, targetId, reason, details, evidenceUrl; resource, id, status, approvalStatus, approvalVersion, rejectionReason, enabled | Backend yêu cầu đăng nhập/admin tùy route; Data API kiểm tra nhiều enum và chiều dài. Cần kiểm thử biên, quyền và trạng thái riêng cho từng resource. |
| `POST /ai/chat`, `GET /ai/brain/profile`, `POST /ai/brain/feedback`, `DELETE /ai/brain/reset` | message, context, history; action, query, productId, helpful; x-session-id | Hồ sơ/feedback/reset yêu cầu token; chat nhận token tùy chọn, phiên khách tạm và không lấy danh tính từ client. Đã kiểm tra giới hạn input và cách ly phiên bằng mock; dữ liệu vận đơn minh họa được gắn nhãn. |

Bảng ghi các điểm đã đọc và test cụ thể; chưa chứng minh mọi trường, nhánh quyền hoặc tình huống lỗi đều đã được kiểm chứng. Ưu tiên rà tiếp các mục còn nêu hạn chế, nhất là dữ liệu đính kèm và các nhánh quyền còn thiếu. Thay đổi contract phải đối chiếu client trước.
